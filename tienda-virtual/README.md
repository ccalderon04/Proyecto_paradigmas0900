# ARRANCAR SERVIDOR FRONTEND
# USAMOS Node.js 20+ · Next.js 16 (App Router) · TypeScript 5 · Tailwind CSS 4
## INSTRUCCIONES:

**ve a la carperta del tienda-virtual**
>cd tienda-virtual

**Corre el comando**
>npm install

**Crear el archivo .env.local en la raiz de tienda-virtual**
>Colocamos la siguiente linea
NEXT_PUBLIC_API_URL=http://localhost:8000

**Levantamos el servidor**
>npm run dev
